# Changes to the Idea – August 5, 2026

## Overview
This document outlines the architectural updates made to SRS V4 on `August 11, 2026`, to refine the core product concept and streamline the MVP stage.

---

## Key Updates
### 1. Adding Redis Caching
**Description:**
Integrated an in-memory **Redis** cache alongside PostgreSQL to handle high-concurrency traffic during peak competition events.

**Key Impacts:**
* **Real-Time Leaderboards:** Offloads ranking aggregations to Redis Sorted Sets (`ZSET`), achieving leaderboard response times of <= 50ms.
* **Database Offloading:** Protects the primary database from connection pool exhaustion during traffic spikes (up to 2,000 concurrent viewers).
* **Rate Limiting:** Enforces high-speed tracking for OTP requests and voting endpoints to prevent service abuse.
